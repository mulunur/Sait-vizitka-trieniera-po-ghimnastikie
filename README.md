# Сайт-визитка Дарьи Каденковой

Одностраничный сайт на React + Vite.

## Структура

- `src/App.tsx` — разметка и тексты сайта
- `src/index.css` — все стили
- `public/` — файлы, которые копируются как есть (видео, постер, иконка, robots.txt)
- `index.html` — заголовок страницы и мета-теги

## Команды

```bash
npm install      # один раз: установить зависимости
npm run dev      # локальный просмотр с автообновлением
npm run build    # сборка для хостинга → папка dist/
npm run preview  # посмотреть собранную версию
```

## Публикация

Загрузите **содержимое** папки `dist/` на хостинг (в корень сайта или любую папку) —
пути относительные, дополнительная настройка сервера не нужна.
